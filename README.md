📊 Simulador de Investimentos em Fundos Imobiliários
Sobre o projeto

Este projeto apresenta um simulador desenvolvido em Excel para estimar a evolução de investimentos em Fundos de Investimento Imobiliário (FIIs).

O objetivo é permitir que o usuário simule diferentes cenários de investimento considerando principalmente:

💰 Aporte mensal
📅 Prazo do investimento
📈 Taxa de rendimento mensal
🔄 Reinvestimento dos rendimentos
💵 Patrimônio acumulado ao longo do tempo
Como utilizar
Abra o arquivo Simulador_Investimentos_FII.xlsx.
Informe o valor que deseja investir mensalmente.
Informe o período do investimento em anos.
Informe a taxa de rendimento mensal estimada.
Analise os resultados apresentados pelo simulador.

O modelo permite visualizar como aportes recorrentes e a capitalização dos rendimentos podem influenciar a evolução do patrimônio ao longo do tempo.

Objetivo

O projeto foi desenvolvido com finalidade educacional e de simulação financeira, permitindo comparar diferentes cenários de investimento.

Os resultados são estimativas matemáticas e não representam garantia de rentabilidade futura.

Tecnologias utilizadas
Microsoft Excel
Fórmulas financeiras
Modelagem de cenários
Análise de dados
Visualização de informações
Exemplo de aplicação

O usuário pode comparar cenários como:

Cenário	Aporte mensal	Prazo	Rendimento mensal
Conservador	R$ 500	10 anos	0,6%
Moderado	R$ 1.000	10 anos	0,8%
Agressivo	R$ 1.500	15 anos	1,0%
Observação

Este simulador possui finalidade educacional e não constitui recomendação de investimento.
